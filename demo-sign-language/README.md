**SNAPSIGN — เดโม่ระบบรู้จำท่ามือ**

เดโม่แยกจากไฟล์วิจัยเดิมทั้งหมด ใช้เว็บเบราว์เซอร์และกล้อง ประมวลผลด้วย MediaPipe และฝึก LSTM ด้วย TensorFlow.js ภายในเครื่อง ไม่ต้องมี Python package เพิ่ม และไม่ต้องใช้ API key

**เริ่มใช้งานบน Windows**

คลิก `start-demo.cmd` เพื่อรัน แล้วเปิด http://localhost:5173 ใน Chrome หรือ Edge และอนุญาตกล้อง หรือรันใน PowerShell:

```powershell
cd C:\work\Seminar\demo-sign-language
npm start
```

ต้องติดตั้ง Node.js ก่อน ไม่ต้องรัน npm install เพื่อเปิดเดโม่ ไฟล์ `vendor/` ที่ดาวน์โหลดไว้แล้วใช้รันในเครื่องได้ หากย้าย source โดยไม่มีโฟลเดอร์นี้ ให้ดาวน์โหลดไฟล์โมเดลและไลบรารีหนึ่งครั้งด้วย Python 3:

```powershell
python scripts/download_assets.py
```

หยุดเซิร์ฟเวอร์ด้วย Ctrl+C หากพอร์ต 5173 ถูกใช้แล้ว:

```powershell
$env:PORT = '5174'
npm start
```

อย่าเปิด index.html ด้วย file:// เพราะกล้องและ ES modules ต้องใช้เว็บเซิร์ฟเวอร์

**ฟังก์ชันที่ทำได้**

1. เปิดกล้องหน้า/หลัง ตรวจจับมือได้สูงสุด 2 มือ และแสดงจุดสำคัญของมือ
2. รู้จำท่าพื้นฐาน 7 แบบจากโมเดล MediaPipe เช่น ฝ่ามือเปิด กำมือ ยกนิ้วโป้ง และท่า I Love You ของ ASL ชื่อบนหน้าจอเป็นชื่อท่าที่สังเกตได้ ไม่ได้จับคู่เป็นคำภาษามือไทยโดยอัตโนมัติ
3. ปรับคะแนนขั้นต่ำ กรองท่าที่ไม่นิ่ง และลดการเพิ่มคำเดิมซ้ำขณะค้างท่า เมื่อต้องการคำเดิมอีกครั้งให้เอามือออกประมาณครึ่งวินาทีแล้วทำใหม่
4. รวมคำเป็นข้อความ ลบทีละคำ คัดลอก บันทึก .txt และอ่านออกเสียง การต่อคำยังไม่ใช่การแปลประโยคหรือแก้ไวยากรณ์
5. โหมดข้อมูลจำลองสำหรับดูหน้าจอและซ้อมนำเสนอ ไม่ต้องใช้กล้อง ผลจำลองติดป้ายทั้งบนหน้าจอและในไฟล์ข้อความ ไม่มีคะแนนความมั่นใจปลอม และใช้เก็บตัวอย่างฝึกไม่ได้
6. เก็บตัวอย่างคลิปท่ามือ ตั้งชื่อคำเอง ฝึก LSTM จริงในเบราว์เซอร์ แล้วเลือก “โมเดลของฉัน” เพื่อทดสอบ
7. ส่งออก/นำเข้าชุดข้อมูล และส่งออก/นำเข้าโมเดลไฟล์ JSON เดียวพร้อมชื่อคำ

**ทดลองฝึกโมเดลของคุณ**

1. เปิดกล้อง เพิ่มชื่อคำอย่างน้อย 2 คำในส่วน “สร้างโมเดลของคุณ”
2. กด “เก็บตัวอย่าง” ของคำนั้น มีเวลาเตรียมตัว 1.5 วินาที จากนั้นทำท่าให้ครบหนึ่งครั้งในช่วงประมาณ 2 วินาที เก็บ 16 เฟรมที่ประมาณ 8 เฟรมต่อวินาที ถ้าประมวลผลช้า คลิปอาจนานกว่านี้
3. เก็บอย่างน้อยคำละ 3 คลิป แนะนำ 10 คลิปขึ้นไป เปลี่ยนมุมและระยะพอประมาณ เลือกท่าให้ต่างกันชัดเจน คลิปต้องตรวจพบมืออย่างน้อย 75% ของเฟรม
4. กด “ฝึกโมเดล LSTM” กล้องจะหยุดระหว่างฝึก รอครบ 25 รอบ หรือกดยกเลิกระหว่างฝึก
5. เปิดกล้องอีกครั้ง แอปจะเลือก “โมเดลของฉัน” ให้ ทำท่าที่ฝึกตามจังหวะใกล้เคียงคลิปเดิม การทำนายเริ่มหลังมีข้อมูลประมาณ 2 วินาที
6. บันทึกโมเดลและส่งออกชุดข้อมูลไว้ โมเดลจะไม่คงอยู่เมื่อรีเฟรชจนกว่าจะนำเข้าไฟล์กลับมา ส่วนชุดข้อมูลพยายามบันทึกใน localStorage ของเบราว์เซอร์ หากพื้นที่เต็มจะแจ้งให้ส่งออก

ชื่อคำในชุดข้อมูลเป็นป้ายกำกับที่คุณตั้งเอง แอปไม่ได้ตรวจสอบว่าท่านั้นเป็นภาษามือไทยที่ถูกต้อง ควรให้ผู้ใช้หรือผู้เชี่ยวชาญภาษามือไทยตรวจสอบคู่คำ–ท่าก่อนนำไปใช้ในโครงงาน

รองรับสูงสุด 12 คำ คำละ 40 คลิป รวมไม่เกิน 300 คลิป ไฟล์นำเข้าไม่เกิน 20 MB ถ้าข้อมูลเปลี่ยนหลังฝึก ต้องฝึกใหม่จึงจะอัปเดตโมเดล ชุดข้อมูลนำเข้าจะแทนที่ชุดปัจจุบันหลังยืนยัน

**ขอบเขตของเดโม่**

- เป็นเว็บเดโม่ที่ปรับหน้าจอตามขนาดอุปกรณ์ ยังไม่ใช่ไฟล์ติดตั้ง Android/iOS
- โมเดล LSTM เป็นการจำแนกคลิปเป็นคำหรือวลีที่กำหนดไว้ ไม่ได้แปลภาษามือต่อเนื่องแบบอิสระ ไม่รู้จักคำที่ไม่ได้ฝึก
- ใช้เฉพาะจุดมือ ยังไม่มีสีหน้า ปาก และท่าลำตัว ซึ่งสำคัญต่อภาษามือหลายรูปแบบ
- คะแนนความมั่นใจจาก softmax ไม่ใช่ความแม่นยำจริง โมเดลอาจมั่นใจสูงกับท่าที่ไม่รู้จัก ค่า loss ที่แสดงมาจากชุดฝึก ไม่มีคะแนนจากชุดทดสอบแยก
- การเปรียบเทียบงานวิจัยต้องเพิ่มการแบ่งข้อมูลตามบุคคล/รอบถ่าย ชุดทดสอบแยก macro-F1/confusion matrix และวัดความเร็วบนอุปกรณ์เป้าหมาย
- ใช้ตำแหน่งมือสองข้างแยกซ้าย/ขวา มีค่าการปรากฏของมือ ตำแหน่งข้อมือ x/y และพิกัด xyz เทียบข้อมือที่หารด้วยขนาดฝ่ามือ รวม 132 ค่า/เฟรม
- โครงสร้าง LSTM(24) → Dense(24, ReLU) → Dropout(0.15) → Dense(จำนวนคำ, softmax) ใช้ Adam และ categorical cross-entropy
- วิดีโอไม่ถูกส่งออก เฉพาะพิกัดมือถูกเก็บเมื่อสั่งบันทึก และโมเดลอยู่ในเบราว์เซอร์ เสียงอ่านใช้ Web Speech API ซึ่งขึ้นอยู่กับระบบปฏิบัติการ/เบราว์เซอร์และบางเสียงอาจใช้อินเทอร์เน็ต
- เมื่อสลับแท็บหรือออกจากหน้า กล้องจะหยุดเพื่อคืนอุปกรณ์

**การเปิดจากโทรศัพท์**

หน้าจอรองรับขนาดโทรศัพท์ แต่เซิร์ฟเวอร์เริ่มต้นผูกกับ 127.0.0.1 บนคอมพิวเตอร์เท่านั้น localhost บนโทรศัพท์ไม่ใช่คอมพิวเตอร์ สำหรับ Android ที่มี ADB ใช้ `adb reverse tcp:5173 tcp:5173` แล้วเปิด http://localhost:5173 บนโทรศัพท์ได้ อีกทางคือนำไฟล์ขึ้นโฮสต์ HTTPS ที่เหมาะสม กล้องผ่าน HTTP ของ IP ในเครือข่ายมักถูกเบราว์เซอร์ปิดกั้น

**ไฟล์หลัก**

| ไฟล์ | หน้าที่ |
|---|---|
| index.html / styles.css | หน้าจอภาษาไทยและการแสดงผลบนมือถือ |
| app.mjs | กล้อง MediaPipe การเก็บคลิป ข้อความ และสถานะแอป |
| core.mjs | การสกัดคุณลักษณะ ตรวจข้อมูล และกรองผลที่ไม่นิ่ง |
| ml.mjs | ฝึก ทำนาย ส่งออก และนำเข้า LSTM |
| server.mjs | เซิร์ฟเวอร์ไฟล์ในเครื่อง ไม่รับอัปโหลด |
| scripts/download_assets.py | ดาวน์โหลดไลบรารีและโมเดลที่ระบุเวอร์ชัน |
| vendor/manifest.json | URL ขนาด และ SHA-256 ของไฟล์ที่ดาวน์โหลด |
| tests/ | การทดสอบข้อมูล กล้อง และโมเดล |

**ตรวจสอบโปรแกรม**

```powershell
npm test
```

ทดสอบในเบราว์เซอร์ต้องมี Chrome และติดตั้ง dependency สำหรับพัฒนา (`npm ci`) เปิดเซิร์ฟเวอร์ไว้อีกหน้าต่าง แล้วรัน:

```powershell
node tests/browser-smoke.mjs
```

การทดสอบอัตโนมัติใช้กล้องจำลองของ Chrome และพิกัดมือสังเคราะห์เพื่อตรวจการทำงานของซอฟต์แวร์ ไม่ใช่ผลประเมินความแม่นยำภาษามือจริง ยังต้องทดลองกับกล้อง มือบุคคลจริง และโทรศัพท์เป้าหมายด้วยตนเอง
